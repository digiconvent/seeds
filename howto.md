# adding a seed

1. look for your project's folder: `seeds/your-github-username/your-repo-name`. not there yet? make it, with just the one category folder you need (`test`, `tutorial` or `preset`) inside. already there? just pick the right category folder.

2. name your file `number_Name.json`. underscores not spaces. only capitalise the first word and real names. pick a number that puts it where it should sit among the others.

3. on github, "add file" > upload or paste it in.

4. when it asks how to save, pick "new branch + pull request", not straight to main.

5. open the pull request.

6. wait a bit. green check = good. red x = click details, see what's wrong, fix the file, it checks again.

7. green? hit merge. done, site updates itself.
